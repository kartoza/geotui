## Overview

GeoTUI is a terminal user interface (TUI) application designed for managing geospatial servers with the familiar dual-pane layout of Midnight Commander. Built with Python using Textual and Rich, it runs on Windows (PowerShell), Linux, and macOS.

## Features

- Midnight Commander-style dual-pane interface
- Beautiful Kartoza-branded color scheme
- Cross-platform (Windows, Linux, macOS)
- Internationalization (English, Portuguese, Spanish)
- Secure credential management
- Keyboard-driven workflow with function key bindings

## Quick Start

```bash
pip install geotui
geotui
```

## Key Bindings

| Key | Action |
|-----|--------|
| Tab | Switch between panes |
| F1 | Help |
| F5 | Copy |
| F6 | Move |
| F7 | Create Directory |
| F8 | Delete |
| F9 | Settings |
| F10/q | Quit |
| Ctrl+L | Cycle language |
