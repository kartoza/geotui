# Internationalization

## Supported Languages

| Code | Language |
|------|----------|
| en | English (default) |
| pt | Portuguese |
| es | Spanish |

## How It Works

GeoTUI uses Python's `gettext` module for internationalization. All user-facing strings are wrapped in the `_()` function.

## Adding Translations

1. Extract new strings:
   ```bash
   xgettext -o src/geotui/i18n/messages.pot src/geotui/**/*.py
   ```

2. Update `.po` files:
   ```bash
   msgmerge -U src/geotui/i18n/locales/pt/LC_MESSAGES/geotui.po src/geotui/i18n/messages.pot
   ```

3. Edit the `.po` file with translations

4. Compile `.mo` files:
   ```bash
   msgfmt -o src/geotui/i18n/locales/pt/LC_MESSAGES/geotui.mo src/geotui/i18n/locales/pt/LC_MESSAGES/geotui.po
   ```

## Runtime Switching

Users can cycle languages with **Ctrl+L** or set `GEOTUI_LANG` environment variable.
