# Getting Started

## Installation

### From PyPI

```bash
pip install geotui
```

### From Source

```bash
git clone https://github.com/kartoza/geotui.git
cd geotui
pip install -e .
```

### Using Nix

```bash
nix run github:kartoza/geotui
```

## Running GeoTUI

```bash
geotui
```

## First Steps

When GeoTUI starts, you'll see a dual-pane interface similar to Midnight Commander:

- **Left Pane**: Shows your local file system
- **Right Pane**: Shows your local file system (or remote server)
- **Header**: Displays the application title and clock
- **Footer**: Shows available function key bindings
- **Status Bar**: Displays connection information and branding

Use **Tab** to switch between panes and **arrow keys** to navigate.
