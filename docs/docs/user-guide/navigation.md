# Navigation

## Dual-Pane Interface

GeoTUI uses a Midnight Commander-style dual-pane layout. Each pane displays a directory tree that you can navigate independently.

## Key Bindings

| Key | Action |
|-----|--------|
| Tab | Switch active pane |
| Arrow Up/Down | Navigate file tree |
| Enter | Open directory / select file |
| F1 | Help |
| F2 | Menu |
| F5 | Copy |
| F6 | Move |
| F7 | Create directory |
| F8 | Delete |
| F9 | Settings |
| F10 / q | Quit |
| Ctrl+L | Cycle language (EN/PT/ES) |

## Pane Indicators

The active pane is highlighted with the Kartoza yellow/orange border. The inactive pane uses the blue border.
